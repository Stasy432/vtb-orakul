# ВТБ.Оракул — исправленная версия прототипа

## Что изменено
- Горизонт прогноза теперь включает ровно 14 или 30 календарных дат, включая стартовую дату.
- Дата окончания горизонта в интерфейсе соответствует последнему включённому дню.
- Фильтрация операций и расчёт периода используют одинаковые границы.
- Таблица операций обозначает показатель как «Остаток на конец дня», потому что модель агрегирует поступления и платежи внутри дня.
- Экспорт CSV теперь содержит дневной прогноз: остаток на начало дня, поступления, платежи, остаток на конец дня, статус и список операций. Это исключает ошибочное представление одного дневного остатка как последовательного остатка после каждой операции.

## Публикация
Замените `index.html` в репозитории GitHub на этот файл и дождитесь обновления GitHub Pages.

## Границы прототипа
Все суммы и даты — демонстрационные. Перенос платежа и ускорение поступления моделируются, но не выполняются автоматически. Помощник в текущей версии — правиловый демонстрационный модуль, не подключённая внешняя нейросеть.
